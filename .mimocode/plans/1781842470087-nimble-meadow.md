# 答题器原理图修复计划

## 概述
对答题器 PCB 原理图进行深度检查后，发现 5 个新问题（3 个严重 + 2 个中等）。

## 严重问题

### 1. D1 (BAT54H) 二极管方向反了
**现状**: 阳极(pin1)→VDD, 阴极(pin2)→LDO输出
**问题**: 电流无法从 LDO 流向 VDD，USB 供电时 MCU 没电
**修复**: 交换 D1 两端连线 — 阳极→LDO输出, 阴极→VDD

### 2. R4 (100kΩ) 接到了 Q1 的 Source 而不是 Gate
**现状**: R4 pin2 → 1070,-495 (Source 网络)，Gate (pin1/1040,-395) 悬空
**问题**: PMOS 栅极悬空，行为不可预测
**修复**: 将 R4 pin2 改接到 Q1 Gate (1040,-395)

### 3. USB D- 接到了错误的 MCU 引脚
**现状**: D- → PB12 (pin11) 而不是 PB10 (pin13)
**问题**: PB10 才是 USB D- (UD-) 引脚，PB12 是 SCS_/RXD1_
**修复**: 将 D- 线从 MCU pin11 改接到 pin13

## 中等问题

### 4. VSW (MCU pin4) 悬空
**现状**: 无任何连线
**问题**: 按 CH571F 数据手册，VSW 需要接电容到 GND
**修复**: 添加 100nF 电容从 pin4 到 GND

### 5. 天线路径有两个冗余 0Ω 电阻
**现状**: R6 + R7 都是 0Ω 串联在 MCU ANT 和天线之间
**问题**: 冗余，除非预留匹配网络位置
**修复**: 移除一个 0Ω，或替换为匹配网络元件（如需要）

## 验证方法
- 修复后逐项重新走线验证每个连接
- 检查所有电源路径是否完整
- 确认 USB 数据线连接正确
