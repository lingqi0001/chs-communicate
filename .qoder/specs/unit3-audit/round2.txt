## 3.1 The Chain Rule

这一节相比之前进步最大。你现在终于不是拿

\[
g'(x)\Delta x
\]

冒充真实的 \(\Delta u\)，而是真的计算：

\[
\Delta u=g(x+\Delta x)-g(x)
\]

以及：

\[
\Delta y=h(u+\Delta u)-h(u)
\]

然后先得到 finite identity：

\[
\frac{\Delta y}{\Delta x}
=
\frac{\Delta y}{\Delta u}
\frac{\Delta u}{\Delta x}
\]

再缩小 \(\Delta x\)，最后进入 Chain Rule。**这个教学逻辑现在非常漂亮，我会保留。**

但当前 visual 仍然有一个 **P0 级别数学语义冲突**。

### 问题一：图画的是 finite change，顶部的 `× rate` 却还是 instantaneous derivative

现在 `mapSteps()` 里：

```js
riseLabel: 'rise Δu = ' + env.duReal
gain: '× ' + env.dux
```

也就是下面的 rise 是真实：

\[
\Delta u
\]

但上面那个乘数还是：

\[
g'(x)
\]

以默认：

\[
g(x)=3x^2+1,\quad x=0.8,\quad \Delta x=0.05
\]

为例：

\[
g'(0.8)=4.8
\]

所以 visual 顶部写：

> × 4.8

但是实际：

\[
\Delta u
=
g(0.85)-g(0.8)
=
0.2475
\]

而：

\[
4.8(0.05)=0.24
\]

两者并不相等。

也就是说 visual 同时表达：

> run = 0.05  
> × 4.8  
> rise = 0.2475

学生自然会理解成：

\[
0.05\times4.8=0.2475
\]

但这是假的。

而且你后面还故意把 \(\Delta x\) 放大到 0.18，强调 finite change 与 tangent prediction 会分开，这会让这个冲突更加明显。

### 应该怎么改

在 Chain Rule reveal 之前，顶部 multiplier 应该显示真正 finite ratio：

\[
\times\frac{\Delta u}{\Delta x}
\]

第二层显示：

\[
\times\frac{\Delta y}{\Delta u}
\]

例如：

```text
finite rate × 4.95
```

而不是：

```text
× 4.80
```

等进入 instantaneous-rate screen 后，再把顶部切换成：

```text
du/dx = 4.80
dy/du = ...
```

也就是说 visual 本身应该经历：

```text
finite ratios
       ↓ Δx → 0
instantaneous rates
```

这才能和你现在非常好的教学流程完全一致。

三层 transfer `mapSteps3()` 也有同样的问题。现在它画的是每层真实 finite rise，但顶部 `deepR1 / deepR2 / deepR3` 是 derivatives。需要一起改。

---

### 问题二：\(\Delta u=0\) 时，你现在偷偷把 undefined ratio 换成 derivative

当前：

```js
const ryu =
    Math.abs(duReal) < 1e-12
        ? dyu
        : measStep / duReal;
```

这是为了不显示 NaN，但数学上不成立。

例如：

\[
u=x^2
\]

选择：

\[
x=-\frac{\Delta x}{2}
\]

那么：

\[
(x+\Delta x)^2=x^2
\]

所以：

\[
\Delta u=0
\]

同时：

\[
\Delta y=0
\]

于是：

\[
\frac{\Delta y}{\Delta u}
=
\frac00
\]

**这个 finite ratio 是 undefined。**

但当前程序会把它直接换成：

\[
\frac{dy}{du}
\]

然后屏幕仍然写：

> Δy/Δu = ...

以及：

> Δy/Δx = (Δy/Δu)(Δu/Δx) holds exactly for every step.

这就不对了。

### 正确处理

遇到：

\[
\Delta u=0
\]

的时候就应该直接显示：

```text
Δy/Δu: undefined for this finite step
```

然后一句：

> The factorization of finite ratios requires Δu ≠ 0. Move the step slightly. The derivative form is obtained from the limiting rates, not by dividing 0 by 0.

这其实反而是非常好的 teaching moment。

不要为了 UI 干净而把 undefined 悄悄替换掉。

---

### 还有一个小文案问题

stage ≥ 3 以后 caption 还写：

> Each graph multiplies its own run by its own rate

当你随后把 \(\Delta x\) 扩大到 0.18 时，这句话又会变得像 finite equality。

更准确：

> For an infinitesimal change, each local derivative describes how that layer scales the incoming change. For a visible finite step, the secant ratio and derivative need not match exactly.

### 3.1 当前评价

**视觉理念已经非常强，但上面两个问题必须修。**

尤其第一个属于：

> 图告诉学生的数学和旁边公式不是同一件事。

这是我当前 Unit 3 最优先的问题之一。

# 3.3 Differentiating Inverse Functions

这一节现在也比之前完整很多。

当前流程：

```text
mirror geometry
→ Predict reciprocal
→ reveal rule
→ Chain Rule proof
→ input mistake
→ reciprocal vs negative reciprocal
→ decreasing example
→ arbitrary table
```

结构已经很好。

而且 table 已经不再是 \(x^3\)，这一点改得很对。

不过还有一个重要 mathematical condition 没有写完整。

College Board 对这一条明确写的是：用 inverse definition + Chain Rule 可以求 inverse derivative，**provided the derivative exists**。:chatgpt-content-reference{index="1"}

### 当前 rule 太绝对

现在：

\[
(f^{-1})'(b)=\frac1{f'(a)}
\]

但最好直接写条件：

\[
\boxed{
f(a)=b,\quad f'(a)\neq0
\Rightarrow
(f^{-1})'(b)=\frac1{f'(a)}
}
\]

因为你自己后面马上就展示：

\[
f(x)=x^3,\quad f'(0)=0
\]

inverse：

\[
\sqrt[3]{x}
\]

在 0 有 vertical tangent，没有 finite derivative。

所以当前 side note：

> One is always the reciprocal of the other.

其实与你后面自己的 origin example 矛盾。

应该改成：

> Wherever \(f'(a)\neq0\), the two finite tangent slopes are reciprocals. If \(f'(a)=0\), the inverse may have a vertical tangent instead.

summary 里也最好加这个条件。

---

## “inverse tangent” 这个词最好全部换掉

当前有不少：

> inverse tangent

例如：

> Inverse tangents are reciprocals.

下一节恰好就是：

\[
\arctan
\]

而 “inverse tangent” 本身在英语数学里通常就是 arctan。

所以这里非常容易造成歧义。

统一改成：

> tangent to the inverse function

例如：

> Tangent slopes of inverse functions are reciprocals at corresponding points, when both slopes are finite.

## 还有一句泛化过度的数学文案

当前 arccos 部分说：

> A decreasing function has a negative derivative everywhere on its domain.

以及：

> The derivative of a decreasing function stays negative.

一般数学上不成立。

一个 differentiable decreasing function 可以在某些点 derivative = 0。

准确说法是：

> A differentiable decreasing function has derivative \(\le 0\) where the derivative exists.

而对于 **arccos 特别地**，我们可以进一步知道：

\[
-\frac1{\sqrt{1-x^2}}<0
\]

在：

\[
-1<x<1
\]

所以它这里确实严格 negative。

最好把问题改成：

> The graph of arccos is decreasing, so its derivative cannot be positive. After differentiating \( \cos y=x \), what sign does the algebra force on \((-1,1)\)?

这样比拿一个错误的一般规则来解释更严谨。

### 问题一：你现在同时有两种“第一条规则”的定义

> Outer Rule and Composition

\[

> 所以第一条到底是 Power Rule 还是 Chain Rule？

\]

```text
Procedure: Chain Rule
Outer derivative rule: Power Rule
Inner derivative: 2x
```

这样就完全没有冲突。

## Predict 问 f″ 是什么形状时，屏幕已经把 f″=6x 写出来了

你当前步骤：

```js
depth: 2
```

然后下一步 Predict：

> f′ = 3x² − 3 is quadratic. What shape should f″ have?

运行语义下，这个 Predict 出现时仍然是：

```text

```

但是 `ladderRows()`：

```js

```

所以 depth=2 时 machine 已经显示三行：

```text
f

f″ = 6x
```

而右侧也有：

```js
if (env.depth > 1.5)
    slope of f′ = f″
```

并且把数值直接显示出来。

所以题目问：

> f″ 应该是什么 shape？

学生抬头就看到：

\[
f''=6x
\]

答案已经在屏幕上。

### 应该这样 gate

如果定义：

```text
depth 1 = f
depth 2 = f + f′
depth 3 = f + f′ + f″
depth 4 = ...
```

那么：

```js
max = Math.round(env.depth)
```

而不是：

```js

```

```text

[不要显示 f″]

what should f″ look like?

reveal f″ = 6x
```

你甚至可以保留 f′ 上面的 tangent，让学生**从 slope behavior 推测下一层**。

但不能把下一层名字和公式直接打印出来。

这是当前 3.6 最需要修的地方。

## notation 文案可以更标准一点

现在：

> dⁿy over dxⁿ

建议直接：

\[
\frac{d^ny}{dx^n}
\]

在字符串里至少：

```text
dⁿy / dxⁿ
```

这样学生看到的就是标准 notation。

---

## 有一句小泛化也建议改

Predict explanation：

> Only sin and cos keep their shape.

这个太绝对。

例如 \(e^x\) 也保持自身，很多函数的 higher derivatives 也有周期/结构。

换成：

> Polynomials lose one degree at each differentiation. Sine and cosine behave differently: their derivatives cycle instead of running down to 0.

会准确很多。

## Concavity 现在已经处理好了

这一点不用再改。

你现在说的是：

\[
f''>0\Rightarrow f'\text{ increasing}
\]

\[
f''<0\Rightarrow f'\text{ decreasing}
\]

然后：

> Unit 5 gives this bending behavior the name concavity.

这样就刚刚好，没有再把 Unit 5 的 formal concept 提前变成 Unit 3 核心。
